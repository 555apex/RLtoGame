# 单蛇复盘与答辩练习

## 先独立完成，再核对答案

1. 奖励为 −0.001，折扣 0.99，下一状态在线输出 `[2, 4, 1]`，目标输出 `[5, 3, 2]`。分别计算 DQN 和 Double DQN 目标；真正终止又是多少？
2. Double DQN 选下一动作时，在线网络参与反向传播吗？指出源码证据。
3. 三个训练模型的 20 局平均食物数为 0.5、1.5、2.5。计算跨种子均值和样本标准差。把 60 局合并再算标准差为什么不同？
4. 某模型活了 2000 步却没有吃食物，另一个活了 50 步吃了 2 个食物。按本任务主要指标谁更好？
5. 第 120000 步和 200000 步验证均值一样且都是最大，保留哪个？能再看测试成绩挑选吗？
6. `initial.pt` 和 `resume.pt` 的用途有何区别？只保存在线网络能否精确续训？
7. 本项目启发式避开危险动作，为什么不能偷偷给 DQN 加同样的 mask 来提高成绩？
8. 初始模型与训练后模型有提升，能否断言 Double DQN 的高估问题已被解决？
9. 读自己的最终表：两种算法三个种子的均值分别是多少？每个种子的学习增益是多少？哪一个结论数据尚不支持？
10. 独立运行一个已有模型的验证评估，并把运行目录、命令、结果和你的解释写入个人记录。

## 参考答案

1. DQN：$-0.001+0.99\times5=4.949$；Double DQN 在线选动作 1，再读取目标值 3，得到 2.969；真正终止只剩 −0.001。题目中的终止奖励是手算设定，不代表实际碰撞奖励；实际碰撞还要叠加 −1。
2. 此处不传播；`double_dqn_targets` 的 `@torch.no_grad()` 和 `update` 中 `with torch.no_grad()` 停止目标梯度。当前 `predictions` 的计算在该上下文之外，会更新在线网络。
3. 均值 1.5、样本标准差 1。60 局混合了同一模型受不同环境影响的波动，统计单位不再是独立训练模型。
4. 后者平均食物数更高；前者只是存活更久。报告还应保留截断、碰撞和回报，不能只选好看的指标。
5. 保留 120000 步；测试数据不能参与选模。代码 `score > best_score` 体现严格大于。
6. `initial.pt` 是零更新模型，可评估但不含完整训练状态；`resume.pt` 还含目标网络、Adam、回放池、随机状态、环境和进度。只存在线网络不足以精确恢复。
7. 规定 DQN 不屏蔽危险动作，启发式则明确定义了安全筛选。给 DQN 加 mask 会改变对照因素，必须另立实验并保留原始基础结果。
8. 不能。学习增益比较更新前后表现，高估需要额外的真实回报/价值估计证据。算法名或目标数值更小不能代替证据。
9. 用报告逐种子行逐项减去相同种子的 initial，不要用跨种子平均数替代个体变化。结论必须与你实际看到的数一致；没有证明普遍优势、全局最优或满盘能力。
10. 参考 README 命令；新目录有逐局 CSV 和 manifest。学生实际运行前，此项仍是待完成，不能预填已掌握。

## 5 分钟答辩顺序

| 时间 | 讲解任务 | 现场证据 |
| --- | --- | --- |
| 0:00–1:00 | 用棋盘说明状态、相对动作和奖励叠加 | 演示窗口暂停并单步 |
| 1:00–2:00 | 手算一个 DQN / Double DQN 目标 | 上面的第 1 题及目标函数 |
| 2:00–3:00 | 说明公平比较与三层种子拆分 | 配置差异、冻结清单 |
| 3:00–4:00 | 展示真实表格并解释学习增益和不足 | 最终测试表与训练曲线 |
| 4:00–5:00 | 解释循环和碰撞案例、AI 辅助范围 | 动作轨迹、个人记录 |

回答“为什么效果不好”时，先陈述观察：食物数、循环周期、碰撞位置，再给出待验证假设。不要说“训练不够所以必定加训就好”，也不要用检查全部通过保证策略有能力。
