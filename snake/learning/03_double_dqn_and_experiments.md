# 第三课：Double DQN 与可信实验

你需要先能解释第二课的 Q 值、目标网络、回放池和一次反向传播。本课的目标是：手算两种 TD 目标，读懂两行核心代码，并判断一张实验表能支持什么结论。建议分两次各 45 分钟学习，最后用 30 分钟独立复盘。

## 1. 为什么还要改变 DQN？

设某个状态的三个动作真实价值都为 2，但网络估计为 `[1, 4, 2]`。DQN 取最大值 4。换一组估计误差，最大值仍容易挑中偏高的那个。这个例子解释“最大化与估计误差”的关系，不能证明本项目每次 Q 值都高估。

DQN 已经有在线网络和目标网络。Double DQN 的变化是：让在线网络选下一动作，再让目标网络评价该动作。它没有增加第三张网络，也没有修改游戏规则。设计来源是 [van Hasselt 等人的 Double DQN 论文](https://arxiv.org/abs/1509.06461)；先读摘要与第 3 节的 Double DQN 目标，Atari 结果暂时跳过。

## 2. 用同一组数字手算

令奖励 $r=1$，折扣 $\gamma=0.9$，下一状态在线网络输出 `[4, 2, 1]`，目标网络输出 `[1, 8, 3]`。

普通 DQN 用目标网络最大值 8：

$$y_{DQN}=1+0.9\times8=8.2.$$

Double DQN 先看在线网络：最大值在动作 0；再读取目标网络的动作 0，得到 1：

$$a^*=\arg\max_a Q_\theta(s',a)=0,\qquad y_{DDQN}=1+0.9\times1=1.9.$$

若转移真正终止，两者均为 1。若只是达到 2000 步外部上限，两者继续使用下一状态价值。这里“下一状态”必须是 reset 前的最后观测，不能拿新一局的出生状态替代。[Gymnasium 时间限制说明](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/)解释了这一区别。

数字较小并不自动代表估计更准确；我们没有给出真实 Q 值。两种网络对最大动作意见一致时，两种目标也可能相同。

## 3. 把公式定位到代码

按此顺序阅读，不需要一次通读整个仓库：

| 文件与函数 | 要回答的问题 |
| --- | --- |
| `agents/dqn.py::double_dqn_targets` | `argmax(dim=1)` 为什么沿动作维？ |
| 同函数的 `gather` | 如何为 batch 中每条经验取出它选中的动作值？ |
| `DQNAgent.update` | 分支外的损失、优化器和裁剪为什么共用？ |
| `training.py::Trainer.interact` | 更新步、同步步和验证步如何计数？ |
| `configs/dqn.json` 与 `double_dqn.json` | 除算法名外是否完全一致？ |
| `final_experiment.py::freeze` | 最优模型用什么数据选择？ |
| `final_experiment.py::aggregate` | 标准差究竟对哪些数计算？ |

核心数组形状是 `[B, 3] → [B, 1] → [B]`。`argmax` 返回每行最大值的位置；`gather(1, next_actions)` 读取对应列；`squeeze(1)` 移除单列维度。目标计算使用 `no_grad`，在线网络虽然参与选动作，此处也不反向传播。实际梯度来自当前状态 `Q(s,a)` 的预测误差。

## 4. 三个训练种子和二十个环境种子

训练种子控制初始权重及派生的探索、经验采样、训练环境选择随机源。同一个模型在 20 个环境种子上运行，可以看到初始食物布局等变化，但不能替代重新训练三个模型。

先分别计算每个训练种子的 20 局均值 $m_0,m_1,m_2$，再计算：

$$\bar m=(m_0+m_1+m_2)/3,\qquad s=\sqrt{\frac{\sum_{k=0}^2(m_k-\bar m)^2}{3-1}}.$$

例如三个模型的均值为 `1, 2, 3`，跨训练种子均值为 2，样本标准差为 1。不要把 60 局的标准差标成“训练种子波动”，也不要把 $\bar m\pm s$ 称为 95% 置信区间。只有三个训练种子，判断总体优势仍需谨慎。

随机和启发式没有训练种子，本项目各测试 20 局，单独报告回合间标准差。初始网络也不是“均匀随机策略”：随机初始化后取 argmax 可以产生固定偏好，甚至循环。

## 5. 为什么先冻结再测试？

训练用 0–999，验证用 1000–1019，测试用 10000–10019。验证每 10000 步执行 20 局，按平均食物数选 best，同分保留较早模型。训练预算到达后，将六个 best、三个初始对照、配置、代码与哈希写入冻结清单，之后才运行 220 局测试。

验证是选模型的依据，所以验证冠军的成绩可能偏乐观。测试用于最后一次独立衡量；如果根据测试结果反复调整参数，这些种子就不能继续声称是未见测试集。本轮没有把超预算调参或加训混入正式结果。

两种算法同种子初始张量相同，初始对照只评估一次并同时作为两者的学习前基准。随着策略不同，回合长短和经验也会分化；“公平比较”要求相同采样机制和交互预算，不要求强迫两种策略走同一轨迹。

## 6. 如何读自己的真实报告

打开 [单蛇报告](../reports/single_snake_report.md)，先看逐种子表，再看跨种子均值。比较每个种子的初始模型与学习后模型，检查提升是否在三个种子上都出现；再比较 DQN 与 Double DQN。把平均食物数、碰撞和截断一起读，避免把绕圈存活误判成能力强。

如果 Double DQN 没有更高的分数，仍可正确完成受控实验：写明结果不支持当前预算下的改善，并区分“实现检查通过”“发生了参数更新”“测试能力提升”三个层次。失败分析可以提出奖励、探索或表示方面的假设，但没有消融就不能写成已证实原因。

后续独立练习请在新运行目录和单独练习配置上进行，先写假设与预算，再改一个变量，只在训练/验证集合检查现象。已有最终结果已经冻结，不能用它调参后继续称为同一次正式实验。
