# 阶段一报告来源与 QA 记录

## 交付与读者

用户明确选择中文 Markdown 课程实验报告，面向学生和课程评阅者。结构采用摘要、建模、工程、算法、实验、失败、复现与后续工作；技术报告规范中的结果、定义、方法、局限和问题分别落在对应章节。图表为可重建静态 PNG，架构/交互流程为 GitHub 可渲染的 Mermaid。

## 数据边界

- `data/baselines_validation_v1/episodes.csv`：两种固定策略 × 20 个验证种子，共 40 行；不是训练曲线，不包含最终测试数据。
- `manifest.json`：运行时源码与配置哈希、每个源文件哈希、运行时间、依赖版本、种子列表。该次运行发生在报告构建脚本完成前，因此 manifest 不会声称包含后来新增的文件。
- `summary.json`：由同次逐局记录计算，不折扣奖励和、食物数、长度、占用率、步数与结束事件。
- `data/heuristic_seed1000.jsonl`：种子 1000 的启发式完整 66 步轨迹；67 帧 GIF 包括初始帧。
- `data/checks.xml`：当前测试执行记录；`data/benchmark.json`：单次短 CPU 环境吞吐记录，无优化器。

## 验证与限制

- 报告构建器核对每种策略种子 1000–1019、CSV 与 summary 平均食物数、长度 = 食物数 + 3、总奖励 = 各奖励分量和。
- 报告源码片段使用 inspect 从实际启发式函数提取，并检查其及环境源码的哈希与实验 manifest 一致。
- 固定策略标准差是回合间标准差，不能称跨训练种子标准差。
- 图片已查看；Markdown 公式和 Mermaid 保留源码交付，阅读器需要支持数学公式与 Mermaid。推荐 GitHub 或相应 Markdown 预览器。
- 学生未填写的信息明确待填；没有虚构训练、GPU 加速或个人学习结果。
